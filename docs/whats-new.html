الأمان والحماية 01

عشان مفيش حاجة تضيع تاني — لا ملفات ولا داتابيز.

جديد

سلة محذوفات للمشاريع

حذف المشروع بقى نقل للـ Trash لمدة 7 أيام مع نسخة كاملة (ملفات + dump للداتابيز). استرجاع بضغطة أو حذف نهائي.

فين: Settings → Platform → Trash
جديد

Snapshots لكل مشروع

"Snapshot now" قبل أي شغل خطر، وارجع لأي نقطة. بيشمل الـ workspace + الداتابيز.

فين: Project → Snapshots
جديد

نسخ احتياطي للسيرفر كله

remote-backup يومي 03:30 UTC: بيانات المنصة + مشاريع + مفاتيح الوكلاء، مع retention ونسخ خارجي عبر rclone. وremote-restore للاسترجاع.

فين: على السيرفر (systemd timer)
جديد

Audit log

مين عمل إيه: تسجيل دخول، إنشاء/حذف مشاريع، قراءة secrets، تشغيل وكلاء، إعدادات — مع فلترة وتصدير.

فين: Settings → Insights → Audit log
جديد

حدود موارد + حارس ذاكرة

حدود CPU/RAM لكل مشروع من الواجهة، وافتراضيات مشتقة من السيرفر، ورفض تشغيل كونتينر يزوّد عن الميزانية بدل ما السيرفر يقع.

فين: Settings → Platform → Resources، وProject → Settings
جديد

Secrets vault + SSH targets

مكان واحد لتوكن GitHub، سيريالات البلاجينز، ملفات الاعتماد، وSSH لسيرفرات خارجية — يتحقن في كل المشاريع أو مشاريع مختارة. الوكيل يعمل ssh hestia مباشرة.

فين: Settings → Platform → Secrets vault

الشغل اليومي 02

أسرع وصول، وشغل يكمّل لوحده وأنت بعيد.

جديد

Autopilot 🛫

لما الوكيل يوقف قبل ما يخلّص، المنصة تقوله "كمّل لوحدك" لحد <<DONE>> أو <<BLOCKED>>، بحد أقصى جولات ومدة. الـ runs أصلاً بتشتغل على السيرفر ولو قفلت المتصفح.

فين: شريط الشات → Autopilot، وpill في الهيدر
جديد

Auto-test + Test 🧪 (Playwright)

اختبار تلقائي بعد كل تاسك، أو زر Test: آخر تغيير / رابط أو flow / التطبيق كله. Playwright + Chromium مدمجين في كل كونتينر.

فين: شريط الشات → Test / Auto-test
جديد

Playbooks ⚡

7 أوامر جاهزة (مراجعة أمان، تحديث واختبار، تجهيز للتسليم، استيراد/نشر Hestia، فحص موقع، كتابة e2e) بتضبط الـ skills والوضع وتحط الـ prompt.

فين: شريط الشات → ⚡، وSettings → Playbooks
جديد

أوامر / في الشات

/test /deploy /snapshot /preview /review /screenshot، وكل skill وplaybook بيبقى أمر /.

فين: اكتب / في الكومبوزر
جديد

الوصول السريع للـ Preview

زر 🌐 جنب كل مشروع وchip "Preview :8080" في الهيدر: فتح، نسخ، مشاركة 24 ساعة، فتح في Agent Browser، لقطة شاشة.

فين: القائمة الجانبية + هيدر الشات
جديد

تسجيل صوتي → نص (عربي)

ميكروفون في الكومبوزر بالعامية المصرية افتراضياً، مع بديل أدق على السيرفر (OpenAI transcription) اختياري.

فين: زر المايك جنب الإرسال، وSettings → Voice input
جديد

بحث نصي في كل المحادثات

بحث عربي/إنجليزي جوه الرسايل مش العناوين بس، والنتيجة توديك للرسالة نفسها.

فين: خانة البحث في القائمة الجانبية
جديد

لوحة الأوامر Ctrl+K

افتح أي مشروع/شات/صفحة إعدادات أو نفّذ فعل (مشروع جديد، preview، snapshot) من الكيبورد.

فين: في أي مكان
جديد

Home dashboard

شاشة واحدة: المشاريع وحالتها، تنبيهات بأزرار حل، آخر 10 runs بتكلفتها، المهام الجاية بعدّاد، واستهلاك 7 أيام — مع صحة المنصة والذاكرة وآخر backup.

فين: Home في القائمة الجانبية، أو Ctrl+K → Home
جديد

Team mode 👥

سويتش واحد: Claude ينفّذ → موديل تاني يراجع (VERDICT: SHIP/FIX) → Playwright يختبر → لو فيه ملاحظات ترجع للمنفّذ تلقائي، بحد أقصى دورتين. الشاتات المساعدة مخفية وتقدر تفتحها.

فين: Run options → Who works on it
جديد

مكتبة Prompts + رسائل العملاء

نصوصك المتكررة بضغطة (بحث، اختصار /s-wpfix، "Save as snippet" من أي رسالة)، وقوالب رسائل للعميل بالعربي/الإنجليزي (تسليم، بيانات دخول، الموقع شغال) تتبعت أو تتحط في الـ portal.

فين: Snippets في شريط الشات، وProject → Sharing → Message client
جديد

تكامل GitHub

اربط الريبو بالمشروع، افتح PR من الشات (/pr)، استورد تعليقات المراجعة كتاسك، وwebhook يفتح شات (أو يشغّل agent باختيارك) لما ييجي Issue بلابل معيّن أو تعليق /remote.

فين: Project → GitHub
جديد

مهام مجدولة متقدمة

سلاسل (تاسك بعد تاسك حسب النجاح/الفشل)، شروط قبل التشغيل (رد HTTP، أمر، أيام الأسبوع، نتيجة آخر تشغيل) بدون صرف توكنز، وسجل آخر 50 تشغيل بالملفات اللي اتغيرت والتكلفة.

فين: Schedules في الشات → New/History

العملاء 03

من الفكرة لحد ما العميل يشوف الشغل من غير ما يبقى عنده حساب.

جديد

روابط معاينة عامة

لينك مؤقت (1h/24h/7d) للعميل يفتح الـ preview بدون تسجيل — محصور في البورت ده بس، وبيتلغى فوراً.

فين: Project → Sharing، أو زر 🌐
جديد

Client portal

صفحة عامة للعميل برابط بـ token: حالة المشروع، روابط المعاينة، آخر التغييرات من git، ملاحظتك — RTL.

فين: Project → Sharing → Client portal
جديد

قوالب مشاريع

WordPress جاهز ومثبّت (عربي RTL افتراضي، WooCommerce اختياري، باسورد admin كـ secret)، Laravel، Node، Python. الإنشاء بضغطة والتجهيز في الخلفية.

فين: New project → Template
جديد

لوحة الاستهلاك والتكلفة

توكنز وتكلفة لكل مشروع/عميل/موديل/يوم — عشان التسعير والفواتير. + تقرير أسبوعي على قنوات الإشعار.

فين: Settings → Insights → Usage
جديد

لقطة شاشة ومشاركتها

لقطة من الـ preview بـ Playwright وإرسالها في الشات أو Telegram/WhatsApp أو نسخ لينك مؤقت.

فين: قائمة الـ Preview → Share screenshot، أو /screenshot

الوكلاء والمهارات 04

معاييرك بتتطبق تلقائي في كل مشروع.

جديد

Global skills

مكتبة مهارات على مستوى المنصة تتحقن في كل مشروع: الـ 5 guard skills (always on)، deploy-to-hestia، client-site-import، weekly-site-audit، review-protocol، playwright-e2e، وdelegate-skills (Claude ↔ Codex ↔ Kimi).

فين: Settings → Agents & skills → Global skills
جديد

تفضيلات الرد

لغة ولهجة وأسلوب الرد (عامية مصرية افتراضياً) تتحقن في تعليمات كل مشروع، مع override لكل مستخدم.

فين: Settings → Agents & skills → Reply preferences
جديد

مهام مجدولة جاهزة

مثال شغال: فحص أسبوعي لموقع (تحديثات، TLS، headers، PageSpeed) كل أحد 08:00 بتوقيت القاهرة، وشات "Reviewer" لمراجعة متقاطعة.

فين: مشروع WP → الشاتات

التشغيل والمراقبة 05

تعرف قبل ما العميل يعرف.

جديد

إشعارات Telegram / Webhook / WhatsApp

لما تاسك يخلص أو يفشل أو يحتاجك، وصحة المشاريع، والمهام المجدولة، وإعادة تشغيل المنصة. WhatsApp عبر Meta Cloud API أو CallMeBot.

فين: Settings → Platform → Notifications
جديد

مؤشر صحة المشروع

نقطة ملونة جنب كل مشروع: ذاكرة، الـ preview بيرد؟ مع تنبيه عند التغير (بدون spam).

فين: القائمة الجانبية + هيدر المشروع
جديد

/healthz + heartbeat

نقطة صحة عامة للمراقبة الخارجية (UptimeRobot) وheartbeat لـ healthchecks.io — عشان لو السيرفر وقع تعرف من بره.

فين: Settings → System → Monitoring
جديد

إصلاحات على مستوى الاستضافة

Playwright في الـ base image، حل انقطاع lxc عند قفل SSH (linger)، slugs آمنة للشهادات، WordPress خلف الـ proxy، swap تلقائي، وقت إنشاء الكونتينر قابل للضبط.

فين: installer / base image

الواجهة 06

أبسط وأوضح، وعربي صح.

RTL كامل

الرسايل والجداول والعناوين والكومبوزر بتتجه حسب اللغة تلقائياً، والكود يفضل LTR.

شريط شات مرتّب

موديل واحد "Claude · Opus"، Skills، Playbooks، Test، مايك، إرسال — والباقي في "Run options".

إعدادات مجمّعة

Personal / Agents & skills / Insights / Platform / System + بحث في الإعدادات.

إرشاد أول تشغيل + اختصارات

شاشة ترحيب بـ 3 خطوات، اقتراحات playbooks للشات الفاضي، و? لقائمة الاختصارات.

مستني منك عشان يشتغل بالكامل

  1. WhatsApp: ابعت "I allow callmebot to send me messages" لرقم +34 644 66 32 62 → apikey → Settings → Notifications → WhatsApp → CallMeBot.
  2. Telegram: bot token من @BotFather + chat id.
  3. Secrets vault: ضيف GITHUB_TOKEN وSSH target اسمه hestia واضغط Test.
  4. Codex: اربطه من Settings → Agents عشان المراجعة المتقاطعة.
  5. WAF على Hestia: allowlist للـ IP 191.215.42.26 عشان الفحص الأسبوعي يشوف مواقعك.
  6. الترقية: السيرفر 1 vCPU — 2–4 vCPU / 8GB هتفرق مع Autopilot وAuto-test.
